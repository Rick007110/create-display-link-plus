# Modrinth project fields

Create at https://modrinth.com → **+** (top right) → Create a project.

## Step 1: new project

| Field | Value |
|---|---|
| Name | `Create: Display Link Plus` |
| URL (slug) | `create-display-link-plus` |
| Visibility | Public (it is only visible after Modrinth's review anyway) |
| Summary | `One Create Display Link, many displays: multiple targets per link, label templates, list row formats and clipboard support.` |

## Step 2: project settings

| Setting | Value |
|---|---|
| Icon | `curseforge/logo.png` (512×512, 160 KB; under Modrinth's 256 KiB limit) |
| Description | paste `curseforge/DESCRIPTION.md` (Modrinth uses Markdown, tables work) |
| Categories | **Technology**, **Utility** (optionally **Management**) |
| Client side | **Required** |
| Server side | **Required** |
| License | **LGPL-3.0-only** (GNU Lesser General Public License v3.0 only) |
| Links | Source: https://github.com/Rick007110/create-display-link-plus · Issues: https://github.com/Rick007110/create-display-link-plus/issues |

## Step 3: first version (Versions → Create a version)

| Field | Value |
|---|---|
| File | `build/libs/create_displaylinkplus-1.0.0.jar` (primary file) |
| Version name | `Display Link Plus 1.0.0` |
| Version number | `1.0.0` |
| Release channel | **Release** |
| Loaders | **NeoForge** |
| Game versions | **1.21.1** |
| Dependencies | **Create** (search "Create", the one by the Create team) → **Required** |
| Changelog | same as in `curseforge/PROJECT_FIELDS.md` |

## Step 4: gallery

Add the same in-game screenshots as on CurseForge (see `curseforge/PROJECT_FIELDS.md`). Mark one as featured.

## Step 5: submit for review

Modrinth reviews every new project before it is public; it usually takes from a few hours to a few days.
Things their moderators check: a clear description (done), a correct license (done), correct client/server sides,
and no misleading branding. The page already says "Not affiliated with the Create team".
